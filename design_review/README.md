how useful each reviewer was, is [`../DESIGN_REVIEW_RESPONSE.md`](../DESIGN_REVIEW_RESPONSE.md).

log and the commit history use those names. Only the reviews' text and hand-written code are in git: the renders
and reports made as attachments for a review are regenerated, not kept.
